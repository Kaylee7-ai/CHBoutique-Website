# CHBoutique

A responsive online boutique storefront published with GitHub Pages.

## Pages
- `index.html` — homepage with search entry and departments
- `shop.html` — searchable catalogue with category filters and add-to-bag controls
- `cart.html` — shopping bag with quantity controls and copyable order enquiry
- `contact.html` — contact page (form is currently a preview only)
- `about-us.html` — about the boutique
- `hero3D.html` — animated CSS 3D-style brand feature

## Shared files
- `style.css` — responsive styling
- `products.js` — sample catalogue data
- `app.js` — search, category filtering and local shopping-bag behaviour

## Important before accepting orders
The catalogue currently contains sample display items, not confirmed inventory. Replace sample product details and imagery with real products, confirm all prices and stock, add the official contact channels, and connect a secure order/payment workflow before taking customer payments. The contact form is not yet connected to a message service. The cart is stored in the visitor's browser and its order summary can be copied; it does not submit orders to a store backend.
